Description:



Tetris trials is a different twist on Tetris, mixing it with objectives and tower defence. The goal of the game is to rack up as much score as you can, while pushing ghosts back by completing objectives and getting buffs. Failing to complete these objectives can have negative effects, so you should be cautious. As the game goes on, it will become more challenging. Aim for the highest score!



How the game exactly works:
The game plays as normal Tetris. Every so often, an objective will be given to you and a ghost will also spawn (these have different timings). Completing objectives within the set time rewards you by removing a ghost, and failing to complete one in time gives you a debuff. Completing an objective when there are no active ghosts rewards you with a buff. If a ghost manages to reach the castle, you lose 1hp. If you hp reaches 0, you lose! Normal Tetris loss conditions also still apply. As the game goes on, it will get faster and faster, so be ready!



Requirements



\- Java Development Kit version 26 (JDK 26).

\- Apache Maven 3.9.16

\- The AbsoluteLayout-SNAPSHOT.jar, included in the lib folder

\- NetBeans (optional but easy).



How to build the project using NetBeans:



1\. Open NetBeans.

2\. Select File -> Open Project -> CBL-Project

3\. Right-click the project and select Clean and Build.

4\. Wait until it says BUILD SUCCES.

5\. The .jar will be in the target folder.



How to build the project using command prompt:



1\. Make sure Apache Maven and JDK are installed.

2\. Open the project folder containing pom.xml.

3\. Type cmd in the address bar to open command prompt.

4\. Enter "mvn clean package".

5\. Wait until it says BUILD SUCCES.

6\. The .jar file will be in the target folder.



How to run the application using NetBeans:



1\. Open the CBL-Project project.

2\. Right-click the project and select Run.



How to run the application using command prompt:



1\. Build the project.

2\. Find the .jar file in the target folder.

3\. Create a new text file named RunGame.bat in the same folder as the JAR (make sure its .bat and not .bat.txt).

4\. Open the file in Notepad and add the following commands:



&#x09;@echo off

&#x09;cd /d "%\~dp0"

&#x09;java -cp "CBLProject-1.0-SNAPSHOT.jar;lib\\\*" CBLProject

&#x09;pause



5\. Double click runGame.bat



Controls:

\- Left arrow key to move the piece left.

\- Right arrow key to move the piece right.

\- Up arrow or X to rotate the piece clockwise.

\- Z to rotate the piece counter clockwise.

\- U or A to rotate the piece 180 degrees.

\- C to put the current piece in the hold slot.

\- Down arrow to drop the piece slowly.

\- Spacebar to hard drop the piece.
